# obix-core-reactive

> Previous name: `@obinexusltd/obix-core-reactive` — OBIX packages are named without an npm scope since decision D-102 (2026-09-29); the package, its version and its exports are unchanged.

**The Reactive projection — subscribers, `changedKeys`, effects lifecycle.**

```bash
npm install obix-core-reactive
```

## API

```ts
const create = toReactive(artifact);
const r = create({ props: { limitSeconds: 5 } });
const off = r.subscribe((next, prev, meta) => { meta.changedKeys; });
r.dispatch("Start");
r.startEffects(clock);   // scheduler re-checks while(state,props) after each tick
r.stopEffects();
r.state; r.transitions; r.render(); r.validate();
```

Transitions go through `obix-core-ir.applyAction`. `dispatch` no-ops (returns the same
reference, no `transitions++`, no subscriber calls) when an action returns its
input — matching identity semantics like `Start` at the Timer's terminal state.

## Dependency role

`obix-core-spec` + `obix-core-ir` + `obix-core-scheduler/effects`. **Not** a dependency of `obix-core-scheduler/effects`
(that would be a cycle). Consumed by `obix-compiler-equivalence`, `obix-driver-dom`,
`obix-fixture-timer`.

## Level 0 status

✅ State, props, subscribers, `changedKeys`, `every` effects via the injected
clock. Deferred: `after` / `on` effects.
